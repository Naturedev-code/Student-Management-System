# 🎓 Student Management System

A lightweight, command-line **Student Management System** developed in **C**. This application allows users to efficiently manage student records, featuring a clean and aligned console interface for optimal data readability.

## ✨ Features

- **Core Management**: Add, view, and manage student records seamlessly.
- **Clean Tabular UI**: Properly aligned tabular display for student data in the console.
- **Optimized Formatting**: Utilizes `snprintf` and `printf` to ensure precise string formatting, preventing buffer overflows and guaranteeing neat column alignment.
- **Lightweight & Portable**: Built purely in standard C with no external dependencies.
